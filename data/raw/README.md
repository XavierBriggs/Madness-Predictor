# Raw Data

Original NCAA basketball datasets. Do not modify — these are the source of truth.

| File | Description |
|------|-------------|
| `MRegularSeasonDetailedResults_with_poss.csv` | Regular season box scores with possession estimates (26MB, gitignored) |
| `regular_season_detailed_2026.csv` | 2026 season game data |
| `MNCAATourneyDetailedResults.csv` | Historical tournament box scores |
| `MNCAATourneyDetailedResults_with_poss.csv` | Tournament results with possession data |
| `MNCAATourneyDetailedResults_addedrank.csv` | Tournament results with rankings |
| `MNCAATourneySeeds.csv` | Historical tournament seedings |
| `MNCAATourneySlots.csv` | Tournament bracket slot assignments |
| `MTeams.csv` | Team names and IDs |
| `MTeamConferences.csv` | Conference affiliations by season |
| `MConferenceTourneyGames.csv` | Conference tournament results |
| `MMasseyOrdinals_filtered.csv` | Filtered computer rankings |
